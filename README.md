# EquiSports Client Application

Live Site URL: https://equisports-project-b7818.web.app

## Key Features
- Dynamic Responsive Single Page Application (SPA) built with React & Vite.
- Firebase Authentication supporting Email/Password and Google OAuth.
- Persistent Route Guards preventing unauthorized access to private management actions.
- Dynamic theme switching support (Light/Dark mode).
- Custom notifications with SweetAlert2 and interactive Tooltips.

## Tech Stack
- React.js, React Router DOM, Tailwind CSS, Firebase Auth,DaisyUi, Lucide Icons, Swiper, SweetAlert2
